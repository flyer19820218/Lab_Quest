# 物理男孩：實驗室大冒險

一間可以自由走動的 3D 房間、一張實驗桌，以及驗電器、負電棒與接地線。
v2（2026-09-20）：March 化身為可操作的 3D 角色，保留黑髮、方框眼鏡、深藍外套與科學 T 恤。肩、肘、腕及髖、膝、踝可以獨立活動，右手持棒分成遠、中、近三段，左手獨立接地。

## 開啟與遊玩

直接以 Chrome 或其他支援 WebGL 的瀏覽器開啟 `index.html`。
目前 `index.html` 與 `lab_3d_walk_preview_0919_v2.html` 都是 v2。舊版入口 `lab_3d_walk_preview_0919_v1.html`、`src/game.js` 與 `game.css` 保留不變。三維函式庫已存在 `vendor/`，不需建置、CDN 或網路。也可在專案目錄執行 `python3 -m http.server 8765 --bind 127.0.0.1`，開啟 `http://127.0.0.1:8765/`。

- WASD／方向鍵、左下觸控搖桿，或點地板：走動。
- E 或右下「操作實驗桌」：人物自動繞過桌子，走到操作位置。
- 先點桌上的棒或「拿起負電棒」：人物伸手取棒，再抬起。
- 「遠／中／近」，或拖曳手持棒：右手平滑移動到三個位置，肘部自然彎曲，骨長不伸縮。
- 任務二點「左手接地」或桌上接地端：左手伸到接點才導通，右手持棒位置保持不變；再點一次抬手斷地。
- 「離開實驗桌」或 Esc：放回器材，回到自由走動。

任務一完成並答對 +40 經驗；任務二 +60。達到 Lv. 2，器材架出現等大金屬球與琥珀工具箱。獎勵每項只領一次，進度存於本機。金屬球目前是已獲得的陳列器材，其實驗任務尚未開放。

## 科學與人物

`src/engine.js` 沿用已驗證的靜電規則，未改數值或判斷。
負棒不接觸圓盤；電子只在導體與接地通路上移動。驗電器內的金屬桿只到金箔鉸點。
實驗桌、人物、手臂、器材是 WebGL 立體物件；帶電棒拿起後成為手掌節點的子物件。雙臂使用固定骨長的兩節骨架求解，走路具有膝部彎曲及反向擺臂。四張 March 圖片作為建模／動作參考，不會直接變成遊戲網格。

電荷數是可數的示意單位，非庫侖與精密電場模擬。學習內容仍為兩關；沒有把外觀圖誤當成可互動角色。
