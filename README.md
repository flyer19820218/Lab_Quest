# 物理男孩：升學實驗室

第 3 步的可操作靜電工作檯。獨立於既有 `Physical-Boys` 教材，沒有修改原教材。

## 開啟

直接用瀏覽器開啟 `index.html`。不需安裝套件、不需建置，也不依賴 CDN 或網路服務。若要在同一個 Wi-Fi 的手機上測試，可在本目錄執行 `python3 -m http.server 8000`，再以手機開啟電腦的區域網路位址。

## 已實作

- 自訂國中生研究員暱稱、兩個可操作任務、本機進度與固定獎勵。
- 任務一：拖負電棒靠近但不接觸；電子僅重新分布，總電荷仍為零，金箔張開。
- 任務二：近棒 → 接地 → 先斷地 → 移棒；留下淨正電。先移棒會讓地面補回電子，回到中性並提供可重試提示。
- 觸控拖曳、靠近／移開按鈕、按住／放開接地，以及單指點按接地模式。
- 鍵盤：聚焦負電棒後用方向鍵；Home 移遠、End 靠近。聚焦接地按鈕後按住 Space 或 Enter。
- 正確驗電器結構：紅色圓盤、絕緣塞、到金箔鉸點為止的金屬桿。金屬桿不延伸到底座。
- 科學狀態獨立於繪圖；電子移動與金箔張角都讀同一狀態。動畫只在物理狀態變更時播放。
- 任務三尚未製作可玩介面；等大球的守恆／等分規則已提供並驗證。

## 檔案

- `index.html`、`styles.css`：手機優先的工作檯與向量器材。
- `src/engine.js`：純 JavaScript 狀態引擎，可供瀏覽器與 Node 共用。
- `src/app.js`：輸入、動畫、任務回饋、本機存檔。
- `tests/engine.test.cjs`：15 項科學驗收，含 3,000 次確定性探索操作。
- `tests/browser.test.cjs`：可選的桌面／手機模擬操作、動畫像素差異、存檔與器材結構驗收。

## 驗證

有 Node.js 時執行 `node --test tests/engine.test.cjs`，或 `npm test`。

瀏覽器驗收另外需要 Playwright、pngjs 與 Chrome：`node tests/browser.test.cjs`。截圖會放在已忽略的 `artifacts/`。

本機實作紀錄與驗證結果見 `STEP3_IMPLEMENTATION.md`。手機模擬不等同真實 iPhone Safari，實機觸控與 Safari 相容性仍需後續驗證。

## 教學模型界線

電荷數是可數的示意單位，不是庫侖。中性狀態使用 12 個固定正電荷與 12 個自由電子，近棒且接地時最多有 4 個電子移至地面。這些示意數值用來清楚呈現守恆、電子不足與操作順序，並非根據真實器材尺寸計算的場強。

兩份原始規格仍保留 P0 的「飛菇」角色文字；本實作依老師後續確認，採 v3 的原創國中生人物方向。既有概念圖直接引用，沒有改寫原始素材。

本原型沒有發布到外部網站，也尚未加入 3D、角色走路、手把、完整任務三或服裝換裝系統。
