# 物理男孩：實驗室大冒險

一間可以自由走動的 3D 房間、一張實驗桌，以及驗電器、負電棒與接地線。
現行版（2026-09-20）：玩家已換成老師提供的藍綠髮、粉衣 3D 女孩。她可自由走動，右手持棒分成遠、中、近三段，左手可碰到桌上的接地端。原本的程序角色只在模型載入失敗時作為後備。

## 開啟與遊玩

以 GitHub Pages 或本機 HTTP 伺服器開啟 `index.html`；3D 模型需要 HTTP，請勿直接用 `file://` 開啟。唯一正式入口是 `index.html`；測試預覽為 `lab_3d_walk_preview_0920_v4.html`。舊的 3D v1／v2 入口與程式已從現行檔案移除。三維函式庫與角色模型均在專案內，不需建置或 CDN。也可在專案目錄執行 `python3 -m http.server 8765 --bind 127.0.0.1`，開啟 `http://127.0.0.1:8765/`。

- WASD／方向鍵、左下觸控搖桿，或點地板：走動。
- E 或右下「操作實驗桌」：人物自動繞過桌子，走到操作位置。
- 先點桌上的棒或「拿起負電棒」：人物伸手取棒，再抬起。
- 「遠／中／近」，或拖曳手持棒：右手平滑移動到三個位置，肘部自然彎曲，骨長不伸縮。
- 任務二點「左手接地」或桌上接地端：左手伸到接點才導通，右手持棒位置保持不變；再點一次抬手斷地。
- 「離開實驗桌」或 Esc：放回器材，回到自由走動。

任務一完成並答對 +40 經驗；任務二 +60。達到 Lv. 2，器材架出現等大金屬球與琥珀工具箱。獎勵每項只領一次，進度存於本機。金屬球目前是已獲得的陳列器材，其實驗任務尚未開放。

## 科學與人物

`src/engine.js` 沿用已驗證的靜電規則，未改數值或判斷。
負棒不接觸圓盤；兩段分離的藍色電子都從最上方金屬圓盤出發，沿金屬桿移到左右鋁箔（每段各 2 個）。接地時電子才沿接地線流出。紅色正電荷固定不動；驗電器內的金屬桿只到金箔鉸點。
實驗桌、人物、手臂、器材是 WebGL 立體物件。`assets/characters/mixamo-walk.glb` 是老師提供的 FBX 轉成的網頁模型，保留蒙皮骨架與原有走路動畫；右手握住負電棒，左手透過骨架動作觸碰已移近的接地端。模型在場景完成後才讀取，若讀取失敗會退回原本的程序角色，不會一直卡在載入畫面。

電荷數是可數的示意單位，非庫侖與精密電場模擬。學習內容仍為兩關；沒有把外觀圖誤當成可互動角色。

## 驗證

- `node --test tests/engine.test.cjs`：17 項科學引擎測試。
- `node tests/game.test.cjs`（需要 Playwright、pngjs 與 Chrome）：走動、碰撞、繞桌、拿棒、握持對位、接地順序、觸控、存檔、升級與實際動畫像素差。
- 測試圖片與報告：`artifacts/game-3d-v5/`（不進 Git）。包含兩段電子移動、桌面、iPad、844×390 與 667×375 手機橫式操作，檢查提示不遮場景、場景和主要操作鈕能同時看見。

原始物理路徑參照 `Physical-Boys/electronics_1.html` 的 `T6_P_PLATE → T6_P_STEM → T6_P_LEAF`。獨立的早期 2D 向量概念稿 `prototype-svg-v1.html` 不是舊 3D 遊戲；它的測試仍由 `tests/browser.test.cjs` 執行。
Three.js r160.1 與隨附的 GLTFLoader 使用 MIT 授權，見 `vendor/THREE-LICENSE.txt`。老師提供的原始 FBX 位於其 Downloads，倉庫只保留網頁用的壓縮 GLB。
