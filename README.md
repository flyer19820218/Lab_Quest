# 物理男孩：我的第一間 3D 實驗室

一間可以自由走動的 3D 房間、一張實驗桌，以及驗電器、負電棒與接地線。
2026-09-19 依老師指定改為遊戲模式；角色沿用核定 v3 的國中生、藍外套、金色飾邊與護目鏡造型方向，以簡易立體模型實作。

## 開啟與遊玩

直接以 Chrome 或其他支援 WebGL 的瀏覽器開啟 `index.html`。
本輪獨立預覽入口為 `lab_3d_walk_preview_0919_v1.html`。三維函式庫已存在 `vendor/`，不需建置、CDN 或網路。

- WASD／方向鍵、左下觸控搖桿，或點地板：走動。
- E 或右下「操作實驗桌」：人物自動繞過桌子，走到操作位置。
- 先點桌上的棒或「拿起負電棒」：人物伸手取棒，再抬起。
- 「伸手靠近」／「移開帶電棒」，或拖曳手持棒：移動手臂與握住的棒。
- 任務二點「另一手接地」或桌上接地端：手按到接點才導通；再點一次抬手斷地。
- 「離開實驗桌」或 Esc：放回器材，回到自由走動。

任務一完成並答對 +40 經驗；任務二 +60。達到 Lv. 2，器材架出現等大金屬球與琥珀工具箱。獎勵每項只領一次，進度存於本機。金屬球目前是已獲得的陳列器材，其實驗任務尚未開放。

## 科學與人物

`src/engine.js` 沿用已驗證的靜電規則，未改數值或判斷。
負棒不接觸圓盤；電子只在導體與接地通路上移動。驗電器內的金屬桿只到金箔鉸點。
實驗桌、人物、手臂、器材是 WebGL 立體物件；帶電棒拿起後成為手掌節點的子物件。手臂用兩節骨架求解，人物可以轉身、走路、伸手和放回器材。

電荷數是可數的示意單位，非庫侖與精密電場模擬。學習內容仍為兩關；沒有把外觀圖誤當成可互動角色。
