# Lab Quest：產品方向與開發討論紀要

> 記錄日期：2026-09-23  
> 性質：方向與待驗證假設；不是已完成的功能清單。  
> 目前倉庫中的 3D 驗電器場景是**研發試做原型**，不是正式遊戲的「第一關」。

> **2026-09-25 方向更新**：物理館電學實驗室以自由探索、玩家主動操作器材及科學探究為核心，先使用 March；靜電球、萊頓瓶、摩擦、感應、接觸，最後以驗電器整合驗證。故事與製作流程分別見 ELECTRICITY_HALL_STORY.md、SCENE_PRODUCTION_SOP.md。舊文中尚未定案的角色、收藏與部署想法，不應當成目前的製作要求。

## 一、想做的遊戲

Lab Quest 希望成為讓孩子願意探索國中自然的原創科學遊戲世界。學生能自由走動、自己決定觀察和操作的器材；科學內容必須正確，並真正參與玩法。此處記錄的是方向，不是既有功能清單。

理想的遊玩循環：

1. 在世界裡探索，遇到有趣的現象或小生物的難題。
2. 觀察、操作器材、提出想法並做實驗。
3. 用理解到的科學規則解決眼前的問題。
4. 獲得道具、能力、收藏或研究室的新變化。
5. 帶著新的可能性探索下一個事件。

例如：理解靜電後可取得原本碰不到的物品；學會浮力後能設計渡河的方法。這些都是**玩法構想**，不是現有功能承諾。獎勵應讓孩子感到發現、擁有和成長；避免只把選擇題包裝成「答對就加 XP」，也不以體力限制、抽卡或強迫每日登入作為核心。

**主要目標是讓孩子喜歡探索與理解科學。商業收入是次要考量。**

## 二、目前原型要驗證什麼

現有驗電器場景是用來測試操作手感、科學呈現方式，以及學生對「在遊戲世界裡做科學」的接受度。它不代表正式遊戲已定型，也不應直接稱為第一關。

知識型事件不必要求孩子反覆重玩同一段。第一輪學生試玩可觀察：

- 能否自行理解移動、接近器材與開始操作。
- 在哪裡卡住、需要老師解說或想跳過。
- 是否願意完成事件，失敗後能否再試。
- 結束後是否想知道下一個科學事件。
- 透過操作能否說出或應用關鍵科學概念。

完成率、卡關點、下一事件的興趣與概念理解，比「同一關玩第二次」更適合作為這個原型的回饋。先做小規模實測，再根據觀察決定正式玩法。

## 三、技術方向：逐步建立可維護的世界

若試玩結果支持繼續開發，目標是一套共用的 Web 遊戲核心，逐步抽出場景、事件／任務、對話、實驗互動、道具與收藏、獎勵與存檔、素材載入等系統。未來新增內容應盡量沿用既有機制；特殊的科學操作仍需個別設計、實作與測試。**不預設所有科學事件都能只靠一份 JSON 產生。**

討論中的部署分工：

| 部分 | 預定用途 |
| --- | --- |
| GitHub | 原始碼、關卡資料、設計與維護文件 |
| Cloudflare Pages | Web 遊戲的發布候選方案 |
| Cloudflare R2 | 大型圖片、音效、動畫與 3D 資產的候選存放處 |
| iOS App | 世界與玩法成熟後再評估的發行形式 |

這是**候選架構**，尚未決定搬遷時間、實際費用或完成部署。尤其不能因為討論了 R2，就把現有素材當成已搬移。網站與未來 iOS 版希望盡量共用遊戲邏輯；是否採用 PWA、App 包裝、原生整合及 App Store 發行，應在真機體驗、離線需求、審核要求和維護成本明朗後再決定。不要為了上架而立即把遊戲重寫成兩套。

## 四、一個人的製作流程與成本

真人核心團隊目前只有老師本人。老師負責遊戲方向、科學內容、學生觀察與最終取捨；AI 可協助需求拆解、程式實作、素材草圖、測試及檢查。所謂 coding agent，可以先從能讀取倉庫、修改檔案、執行測試的現成工具學起，**目前不需要自行開發一套 agent 系統**。重要的操作流程是看得懂改了什麼、在正式發布前試玩，以及能用 Git 回復問題版本。

先使用既有工具與免費額度；API、較高訂閱方案、付費服務或 Apple Developer 會員，都等實際需求和用量出現後再評估。先前談到的月費數字只是粗略情境，**不是預算承諾或成本保證**。大型素材與 AI 生成的實際費用，需要以當時的方案、使用量與官方價格核算。

## 五、接下來的順序

1. **測原型**：邀請少量學生實際操作，記錄卡點、理解情況與對下一個事件的興趣。
2. **定正式體驗**：根據回饋決定可愛角色、世界氛圍、科學事件與獎勵如何結合；不要把試做場景自動算作正式第一關。
3. **建立安全的開發流程**：學會讓 coding agent 看倉庫、提出修改、檢查差異、測試並回復版本；重大遊玩變更先供老師試玩。
4. **製作下一個可玩的科學事件**：用它驗證共用系統、科學互動與素材管理的實際需求。
5. **再擴充與評估發行**：依據學生回饋及維護成本，決定世界規模、Cloudflare 遷移、PWA／iOS、TestFlight 與可能的定價。
