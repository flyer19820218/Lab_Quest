# 萊頓瓶｜重新製作規格

> 狀態：結構可製作；虛擬充放電探究待老師確認<br>
> 來源：原教材未找到萊頓瓶單元，本器材不假稱是原教材移植。

## 已查核結構

- 內導電層與外導電層之間是玻璃絕緣層；本版採金屬箔，不把水當必要零件。
- 頂部金屬端經金屬桿／鏈連到內金屬箔；外金屬箔是另一個獨立端。
- 金屬箔不到瓶口，兩箔不能穿過玻璃接在一起。萊頓瓶是電容器，不是自行產生電荷的電池。
- 可切換外觀、剖面和分層，觀察導體／絕緣體；不讓電子穿過玻璃。

參考：[Smithsonian 實物藏品](https://americanhistory.si.edu/collections/object/nmah_1341624)、[Science History Institute](https://www.sciencehistory.org/stories/magazine/leyden-jar-battery/)、[Science Buddies](https://www.sciencebuddies.org/science-fair-projects/project-ideas/Elec_p049/electricity-electronics/electric-charge-sparks)。

## 虛擬充放電提案（待確認）

採定性的相對電荷單位，不宣稱真實伏特、火花長度或時間。外箔連接模型接地端後，虛擬帶電來源向內箔送入電子；外箔的電子沿外部接地路徑移出，形成等量異號的兩側電荷。移除來源、斷開外接線後，在理想不漏電模型中保持；接通兩端的放電回路後，電子只走外部導線，回到中性。正電區域保持紅色且不當作移動粒子；玻璃仍是隔開兩極的絕緣層。

## 不做

不提供兒童照做的高壓實物製作或人體放電玩法。不以「能量球」、永動火花或電子穿玻璃特效代替原理。未經老師確認前，遊戲只開放結構觀察，不給充放電結果判定。
