# ELEC-00｜電學館前廳：炸毛之謎（設計草案）

狀態：視覺與動作概念已獲老師確認；網頁可玩場景製作中。探究問答與後續科學規則仍須逐關確認。

## 先看見現象，再自願探究

March 由入口進入可自由走動的前廳。中央展示台上的藍綠毛絨角色站在絕緣平台，前爪持續接觸范德格拉夫起電機的**金屬球**。起電後，整頭細毛逐漸向四周散開。開場就能看見現象；走近展示台不自動接任務。學生主動選「觀察」，鏡頭才靠近，讓學生先預測「為什麼每根毛都想離開其他毛？」之後可前往實驗區驗證。

## 科學不變量

- 主裝置是范德格拉夫起電機：不透明金屬集電球、絕緣柱、底座。影片中透明且有紫色放電絲的**電漿球不是這個炸毛實驗的替身**。
- 示範角色站在絕緣平台、手接觸金屬球時，身體與毛髮逐漸帶電；同號帶電的毛髮互相排斥而散開。
- 視覺上不指定毛髮帶正或帶負：符號取決於實際起電機組態，在老師確認前不畫電子流與電荷符號。
- 手離開球後若仍與地面絕緣，毛髮**不應瞬間恢復**；只有電荷經接地／放電散去時，才進入回落狀態。
- 不畫全室閃電、人體透視骨骼或由電漿球觸發炸毛。電漿球若納入電學館，應是另一個有獨立規格的展品。

科學參考：[愛荷華大學范德格拉夫炸毛演示](https://instructional-resources.physics.uiowa.edu/5b1010-van-de-graaff-generator-hair)、[NSTA：離開金屬球但仍絕緣時毛髮可保持豎起](https://www.nsta.org/science-teacher/science-teacher-septemberoctober-2022/hair-raising-fun)、[威斯康辛大學：電漿球的玻璃內放電絲](https://wonders.physics.wisc.edu/plasma-ball-experiments/)。

## 2.5D 畫面與互動

| 畫面狀態 | 學生看見 | 操作 |
| --- | --- | --- |
| 未帶電 | 毛髮貼服；前爪已碰金屬球 | March 仍可自由走動 |
| 起電中 | 毛髮由貼服漸漸向外散開 | 不彈出任務 |
| 帶電保持 | 毛髮形成蓬鬆的立體放射輪廓；手維持接觸 | 主動點「觀察」才進探究對話 |
| 放電 | 只有規則引擎進入接地／放電後，毛髮才回落 | 不用「放手＝立即回落」假動畫 |

風格：16:9 橫式固定 2.5D 視角，暖木與青綠的研究館前廳；金屬球、手部接點與絕緣平台在遊戲鏡頭下可一眼辨認。毛髮要是大量細而略彎的柔軟髮束，不是幾根尖刺。March 是玩家，保持較小比例，不能擋住現象。
